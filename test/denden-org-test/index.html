Denden Org-mode Feature Test

Created on: 2026-09-145 min read (1036 words)
testdendenorgmode

The denden-specific equivalent of org-test.org (which covers generic Org syntax against the old Hugo/go-org renderer) – this file exercises the same ground through the denden backend instead, plus native Org features go-org either doesn't support or org-test.org didn't happen to cover: timestamps, radio targets, LaTeX fragments, inline source, a named and captioned table, :noexport:, COMMENT headings, and multi-term description lists. Hugo shortcodes (org-test.org's own last section) are intentionally absent – decision 10 defers that whole question to Stage 11, except note/tip/warn/sidenote (2026-09-14, "Special Blocks" below): those are no longer Hugo shortcode text at all, but real Org special blocks (#+begin_note etc) and a macro ({{{sidenote(...)}}}) – denden-special-block=/the =sidenote macro, not a shortcode port.
