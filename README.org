The Journey begins..

You know its fascinating to have a personal static website which is rich and valuable for others.

I went with Hugo, writing straight in Org-mode (content/*.org, rendered natively by
Hugo's own org support) since Emacs (GOAT) is the one true way to write.

The theme has been rewritten from scratch a few times, [[https://github.com/idlip/hakimacs][hakimacs]], living in
=themes/emacs/= as a submodule.

I hope its a soothing experience for you to read!
