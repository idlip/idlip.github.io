- Content : [[https://orgmode.org/][Org-mode]], parsed natively via =org-element=.

- Theme : originally [[https://github.com/idlip/hakimacs][Hakimacs]], now its embedded directly in blog site repo and maintained on my own.

- Hosting : Manual build and push =gh-pages= branch

- Fonts : [[https://github.com/idlip/code-d-font][Code D font]] (Recursive font with Nerd Icons patched)
