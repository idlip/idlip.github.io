Biocode Daily is a new platform like [[https://rosalind.info][rosalind]], which offers daily bio-related coding challenges.

Its python oriented currently, which basically gives problems and expects a solution on given example and also on hidden tests.

These hidden tests are the good ones, because you need to solve the problems effectively and cannot just hard code some solutions to get over it. Althought very new, I'm excited to see how it will grow, as I'm highly anticipating a comments section, a way to engage with others and share code with help.
